第一层：产品信息（最少只填产品名）
  用户填：产品名 = "热水管"
  系统自动补：分类=未分类  规格型号="通用"  品牌="普通品牌"  单位="件"  换算=1.0000
  建完可以改。

第二层：售价（最少只填金额）
  用户填：售价 = 2.50
  系统自动补：价格类型 = "零售价"
  不填就不创建售价记录。

第三层：进价（最少只填金额）
  用户填：面价 = 1.50（进价列展示 面价 × 点位）
  系统自动补：供应商 = "面价渠道"  点位 = 1.0000（原价）
  不填就不创建进价记录。

第四层：图片（最少传一张图）
  用户传图就创建，不传就不创建。
  图片不能捏造，没有缺省值。

价格推算规则

所有价格推算都从一个原则出发：每个「规格×品牌」有且只有一个基准单位，其余单位按换算率折算。


═══════════════════════════════════════════════════════════
第一步：搞清楚基准单位
═══════════════════════════════════════════════════════════

每个规格下，用户指定一个单位作为基准。换算系数按「规格×品牌」独立。

例：DN25 这个规格
  伟星：米 = 基准（isBase = true），根 = 1根 = 4米（换算率 = 4.0000）
  日丰：米 = 基准（isBase = true），根 = 1根 = 3.8米（换算率 = 3.8000）

所有库存核算、价格推算，都以基准单位为准。


═══════════════════════════════════════════════════════════
第二步：售价推算
═══════════════════════════════════════════════════════════

场景：伟星 DN25，用户只录了"米"的售价，没录"根"的售价。
      用户切换到"根"时，售价怎么显示？

已知：
  伟星·米·零售价 = 2.50
  伟星·根  换算率 = 4.0000（1根 = 4米）

推算：
  伟星·根·零售价 = 伟星·米·零售价 × 换算率
                  = 2.50 × 4.0000
                  = 10.00

反过来，如果用户只录了"根"的售价：
  伟星·米·零售价 = 伟星·根·零售价 ÷ 换算率
                  = 10.00 ÷ 4.0000
                  = 2.50

取值优先级（列表展示售价时）：
  ① 当前单位有售价 → 直接用
  ② 当前单位没售价 → 拿基准单位售价 × 换算率
  ③ 基准单位也没售价 → 显示 "--"


═══════════════════════════════════════════════════════════
第三步：进价推算
═══════════════════════════════════════════════════════════

进价 = 面价 × 点位（点位来自 supplier_point_rule，无规则默认 1）。
面价是录入值，点位变化永不重算面价；进价按换算率折算到其他单位。

场景：伟星 DN25，用户只录了"米"的面价，没录"根"的面价。

已知：
  伟星·米·供应商A·面价 = 1.50
  伟星·供应商A·点位   = 0.8000
  伟星·根  换算率      = 4.0000

先算基准单位进价：
  伟星·米·进价 = 面价 × 点位
                = 1.50 × 0.8000
                = 1.20

再推算到根：
  伟星·根·进价 = 伟星·米·进价 × 换算率
                = 1.20 × 4.0000
                = 4.80

取值优先级（列表展示进价时）：
  ① 当前单位有进价 → 面价 × 点位
  ② 当前单位没进价 → 基准单位进价 × 换算率
  ③ 基准单位也没进价 → 显示 "--"


═══════════════════════════════════════════════════════════
第四步：不同品牌，换算率不同
═══════════════════════════════════════════════════════════

同一个规格 DN25 下面：

  伟星·根  换算率 = 4.0000（伟星的根，1根 = 4米）
  日丰·根  换算率 = 3.8000（日丰的根，1根 = 3.8米，和伟星不一样长）

  伟星·根·售价 = 伟星·米·售价 × 4.0000
  日丰·根·售价 = 日丰·米·售价 × 3.8000

各算各的，互不影响。


═══════════════════════════════════════════════════════════
第五步：不同规格，单位不同
═══════════════════════════════════════════════════════════

同一个产品"热水管"下面：

  DN25 规格：单位 = 米、根
  DN20 规格：单位 = 米、根

  DN25 的米 和 DN20 的米 是两条独立的 unit 记录。
  DN25 的售价 和 DN20 的售价 各自独立，互不推算。

完整示例：把所有东西串起来
═══════════════════════════════════════════════════════════

热水管 → DN25 → 伟星（spec_brand id=577）

  用户录了：
    伟星·米·零售价 = 2.50
    伟星·米·供应商A·面价 = 1.50
    伟星·根  换算率 = 4.0000
    供应商A·伟星·给水管材·点位 = 0.8000

  系统自动算出：
    伟星·米·进价 = 1.50 × 0.8 = 1.20
    伟星·根·售价 = 2.50 × 4 = 10.00
    伟星·根·进价 = 1.20 × 4 = 4.80

  列表显示（默认单位是米）：
    售价列 = 2.50
    进价列 = 1.20

  用户切换到根：
    售价列 = 10.00
    进价列 = 4.80
