# 质量闸门（每次改完必过）

> 改代码同一轮过本清单。权衡：历史数据不能错 > 录入效率 > 影响不扩散 > 复用 > 性能 > 代码好看。

## 一、变更闭环

- 影响面扫过（单据快照 / 非标行 / 状态机 / 权限码 / 三条交互链）。快照：改数量/单价/只换单位不按关联刷产品名；再插入才整份重抄
- 复用了现有基座，没有新造表格/浮层/输入
- 开单表格无保存按钮；写入统一走确认层（确认才 commitCell，取消/点空白不写）。选品内改档案点格子打开输入浮层（看全文 + 影响范围）。默认确认修改=当前（不列清单）；单位/品牌/分类/售价类型/供应商可改全局（已有同名则并到那个档案，确认层列出本次会改到的数据）。点位可改全局（品牌+分类这一批，已经单独改过的规格不跟着变，确认层列出跟圈组会被改到的规格）。字典格检索下拉。格子划过要看得出能点，确认层不得关掉选品；不走失焦保存、不叠模态。插入选品是明确写。
- 数字列非原生 number
- **手机端（高频）**：点格必须出系统键盘；滑动画布不关浮层。见第六节，不过关 = 失败
- 文档与代码同一轮更新。**文档可视化必须最新**（人确认、项目对齐看这里）；同一轮再改用户文档对应处（AI 会读，落后会按旧基线做错）。选品/档案框架同一轮必须写进 `文档可视化/`，不能只改 markdown
- 前端 `tsc -b` 绿；后端 `npm test` 绿（含开单不变量）

## 二、金标准（违反=失败）

优化/抽象之后，**呈现必须仍是原来的「1」**。先分析旧实现再抽出，禁止拆空另写。

禁止重写或替换：`ProductPicker`、`UnitPicker`、`DsDialog`、`DsInputDropdown`、把 `var(--*)` 塞进 `antd-theme.ts` 的 algorithm。`FloatPanel` 交互契约不许改（左对齐、不按窗口避让、滑动不关）；坐标系以画布舞台叠加层为准，禁止再 portal 到 body 后补 zoom。

三条链不能合成一套 UI：

1. 开单选品 = ProductPicker（复选框 + 插入按钮 + 二级价格；规格行/单位层带换算率列；点名称/换算率/面价/点位打开输入浮层再确认，不换成维护矩阵）
2. 开单选单位 = UnitPicker（点行即选）
3. 产品列表/编辑弹窗维护 = UnitManagePanel / UnitPriceExpandPanel；列表单元格仍是 RecordFieldColumn + Popover

`EntityPanel` 只是从 MatrixTable/UnitManagePanel 抽出的网格基座（`.ds-grid-header/.ds-grid-row`），二者是适配器，不是废弃。

## 三、交互统一铁律

- 选择类面板（开单选品 / 选单位简单列表 / 客户）：**回填宿主只走插入按钮**（选单位简单列表仍可点行即选）。选品里点名称是改档案，点箭头是展开下一层，与插入分开。改档案点格子打开输入浮层（看全文 + 影响范围）。默认确认修改=当前；单位/品牌/分类/售价类型/供应商可改全局（已有同名则并档并列出影响数据；字典格检索下拉）。点位可改全局（品牌+分类这一批，已经单独改过的规格不跟着变）。规格行与单位层有换算率列（粒度品牌+规格+单位，基准固定 1）；单价槽单位已锁定不显示换算。格子划过要看得出能点，确认层不得关掉选品；取消即恢复原样
- 编辑类面板（售价/进价/单位维护）：点行是切换不是插入。格子只展示值，点开确认层再输入，不要每行挂常驻输入框。售价与进价同一套列：类型或渠道 | 面价 | 点位 | 实际价。档案列表不另开点位列

## 四、永久规避缺陷

- **P-010** 编辑弹窗上再叠独占模态
- **P-011** 页面裸像素 / 绕过 COL_WIDTHS
- **P-013** 全表扫描、候选集失控
- **P-014** 开单翻页空行序号撞车 + 提交甩到表尾 + 选品插入与确认层手输双提交
- **P-015** 选品落库单位必须是已加载真实单位，`unitId`+`unitName` 非空；ID 落库前剥离 0/''/null
- **P-016** 滑动画布或锚点滚出屏幕就关选品（手机屏窄就是靠挪画布看完）
- **P-017** 点格唤不出系统键盘：未编辑时把常驻 input/textarea 设成 `readOnly`；先渲染 span/纯文本再 `useEffect`/`setTimeout` 里 `focus()`；为挡 iOS 自动放大而牺牲键盘
- **P-018** 画布缩了但浮层/字号不跟，或用媒体查询重排。缩放必须是远程桌面式整幅画面等比。禁止浮层逃出舞台再补 zoom；禁止为手机另做全屏
- 开单表格：数据列单行、列宽随最长内容完整显示（禁止省略号截断）；格内为文字 / 清除 / 待确认，互不重叠；**全部可打字格走点值确认层**（数量/备注也是，不再常驻输入）；名称/单位/单价选用检索挂在确认层输入上（表格格不挂下拉）；行扩展=当前行，表头扩展=已勾选或全部，禁止把勾选批量按钮放到工具栏；「下方插入」是空行+序号后移，不是复制行；勾选默认关，打开就必须能从表头扩展菜单做批量删除

## 五、v16.5 单位

`unit` 全局字典（名称唯一）；`spec_unit` 承载规格引用与 isBase/isDisplay。解除规格引用只删中间表。

## 六、手机端（高频场景，与电脑同一套界面）

画布仍是 1200px，手机只是可视范围小。**不过关 = 失败**，不要等真机用了才发现。改表格/浮层/输入必过：

| 要达到的效果 | 禁止 |
|-------------|------|
| 点开单格：进确认层，确认层真输入同一手势 focus（数量/备注也是） | 未编辑时 `readOnly`（确认层/lockInput 除外）；span 换成 input 再异步 `focus()`（P-017） |
| 数字格弹出数字键盘 | `type="number"`（光标跳、滚轮误改） |
| 档案格点开确认层后再输入 | 格子 `lockInput` 除外，确认层里仍是真输入框、点得出来键盘 |
| 滑动画布看完选品/确认层，浮层跟着走不关 | 点空白才关；失焦不关（P-016） |
| 键盘弹出可让浮层垂直让位 | 禁止改列宽/字号、禁止弹窗改全屏、禁止为手机另做卡片/汉堡/底栏 |
| 缩放是远程桌面式整幅画面：字体/按钮/表格/浮层/弹窗/间距一起等比；内部仍按 1200px 排；100% 时键盘必须可用 | 媒体查询/@media 改布局；浮层逃出舞台再补 zoom；transform:scale 当主方案；为手机另做全屏弹窗 |
| 浮层/弹窗高密度少留白 | 大块 padding / 为手机加宽留白 / 无 Tab 的维护浮层再套一层灰垫 / 定位外壳铺白底把箭头空隙变成留白 |

实现口令：同一手指手势里对**已经挂在 DOM 上、非只读**的 input/textarea `focus()`（`armNativeInput`）。键盘弹出是哲学允许的唯一运行时破例，不能用来改布局。
