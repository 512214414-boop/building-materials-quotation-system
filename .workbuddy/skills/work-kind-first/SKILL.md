# 一类活（本仓库绑定）

**方法**在 `文档可视化/` 独立组「知识沉淀 · 按一类活来写」。页顶复制 Markdown，喂给下一项目的 AI，再口述新现场。AI 先交一类活切法 + 六条线提纲。

**不要带走**「系统业务设计指导思想」。那是这家店填满的正文（开单 / 配货 / 进货 / 往来 / 售后 + 对象/过程/角色/看数/工具）。

「对照本项目」只是方法做通之后追源的例子，可带可不带。

## 本仓库怎么用

- 改写法、改「给 AI 的用法」：先改可视化「按一类活来写」，同一轮再改本技能指针。
- 改这家店为什么这样：先改「系统业务设计指导思想」（可视化，必须最新），同一轮再改用户文档里对应指针，避免 AI 读到旧基线。
- 本项目新需求：先归开单 / 履约 / 进货 / 往来 / 售后，或归对象 / 过程 / 角色 / 看数 / 工具习惯；读指导思想对应页，再动表和页面。
- 下一项目：只复制「按一类活来写」；切法由新现场出，禁止套开单配货。
