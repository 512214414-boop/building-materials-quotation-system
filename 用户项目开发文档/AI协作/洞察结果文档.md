# 洞察结果文档（唯一任务书）

> 给执行 AI 的现行口径。叙事可刷新；已执行项保留 ✅。金标准见质量闸门。

## 系统要成为什么

建材门店笔记本上的报价 / 开单 / 对账 / 配货 / 交付 / 成本 / 售后 / 归档一体系统。用户是 Excel 资深习惯：点格直输、回车下移、无保存按钮。历史单据是快照，档案改名不影响旧单。

## 交互载体（三层，禁止第四种）

| 意图 | 载体 | 实现 |
|------|------|------|
| 轻提示 | 消息通知 | antd message |
| 填表/确认 | 模态框 | DsDialog，相对 1200px 画布居中 |
| 贴格辅助 | 悬浮定位框 | FloatPanel，挂画布 float 叠加层；交互契约不变 |

Drawer 不做下钻主路径。

## 三条链（不可合并）

1. 开单选品 = ProductPicker
2. 开单选单位 = UnitPicker
3. 档案维护 = UnitManagePanel / UnitPriceExpandPanel + RecordFieldColumn

网格 DOM 可抽到 EntityPanel；点选语义不能抽成一套。

## 工程质量架构（已落地，不是建议顺序）

目标：改一处不炸一片。办法：按已经存在的域边界切开，调用方和界面都还是原来的「1」。

| 切面 | 高内聚 | 低耦合 |
|------|--------|--------|
| 产品写入层 | 一个文件只回答一个域（分类 / 宽表同步 / 存档 / 单位） | 路由和 `import … from 'productService'` 不变 |
| 开单不变量 | 插入位置与档案 ID 剥离只在一处纯函数 | 页面只调用，不再各写一份 |
| 产品编辑弹窗 | 单位区、图片区是区块文件 | 全部 useState 留在容器，不改成分步向导 |
| 表格 | 页面表 = UnifiedTable | 废弃 DsTable 已删，避免下一轮复活 |
| 字典输入 | C16 联系方式一条故事 | 不与 C15、开单选品合成一套 |

**金标准锁定（做了就算失败）**：不重写 ProductPicker / UnitPicker / DsDialog；不改 FloatPanel 交互契约；列表单元格仍走 RecordFieldColumn + Popover；三条链不合并。坐标系以画布舞台叠加层为准，禁止再 portal 到 body 后补 zoom。ProductPicker 仍大，只许以后抽「渲染一行」私有文件，禁止拆空另写。

## 主路径验收

登录 → 产品档案（列表单元格 Popover 维护单位/价格）→ 开单选品落行 → 点行选单位 → 报价确认推进状态。无保存按钮。历史行快照不被档案改名改掉。
