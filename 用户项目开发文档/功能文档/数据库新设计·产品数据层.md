# 产品数据层

> **职责**：产品数据层全部表结构与保存事务的**唯一权威**。UI 交互见《产品管理》；单据引用见《单据与状态机》；通用数据规则（表分层/关联/缺省值/规模驱动）见《数据规范》。
> **层级**：category → product → spec → spec_brand ⇄ brand；unit 挂 spec；**SKU = 规格变体 × 品牌 × 单位**。

## category（分类，扁平）

| 字段 | 类型/约束 | 示例值 | 说明 |
|------|----------|--------|------|
| id | Int PK | 1 | 主键 |
| name | varchar(100) | 管材 | 分类名 |
| sortOrder | Int | 0 | 排序 |
| status | Int 1启用0禁用 | 1 | 状态 |
| createdAt / updatedAt | DateTime | — | 时间戳 |

（v15.3 统一引用类语义：产品分类空输入时由后端 resolveCategoryRef 按名称 ensure「未分类」真实分类记录，分类总是有效记录 id，无 0 魔数）

## 保存事务（saveProduct，唯一权威）

1 前置校验（含 (categoryId,name,specModel) 预检，编辑排除自身，422 友好提示）→ 2 差集清理 → 3 product 建改 → 4 spec 建改 → 5 spec_brand 建改（输入品牌不存在→快捷新增全局档案）→ 6 unit 建改 → 7 brand_unit_conversion → 8 售价/进价 → 9 事务提交重建宽表 → 10 图片文件差集清理。

## 宽表同步时机

saveProduct 提交 / 品牌增删改 / 分类改名 / 单位 isBase/isDisplay 变更 / 售价进价增删改 / 主图变更 / 批量改价 / 停用启用 / 删除 → 重建对应宽表行。

## 产品 ID 生成

应用层时间戳生成（格式 `P+YYYYMMDD+HHmmss+SSS+RND`），createProduct/saveProduct/quickCreateProduct 显式传入覆盖默认值；autoincrement 保留仅作 DB 兜底（子表外键引用约束）。
