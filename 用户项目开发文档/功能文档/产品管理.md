# 功能文档·产品管理

> **职责**：员工端产品档案页与编辑弹窗的页面行为唯一权威。

## 业务目标

在一张页面表里维护可售 SKU（规格 × 品牌），并在一个编辑弹窗里配齐单位、售价、进价、图片；开单处引用同一套单位/价格面板，只换场景。柜台为什么这样检索：见 `文档可视化/` 指导思想 · 销售开单。本页分层：见本页「出发点」。

## 页面构成（范式 A + 范式 B）

```
产品管理页
  ├─ 顶栏：新增 / 关键词搜索（独立）/ 已选条件词（独立，可擦）/ 状态（独立下拉）
  ├─ 页面表：每行 = 宽表一条「规格×品牌」
  │     列：操作、分类、图、产品名、品牌、规格、单位、售价、进价、备注、状态
  └─ 编辑弹窗（点产品名或新增）：一个模态框，事务一次提交
```

页面只声明列与场景，不自写单位面板、价格面板、像素样式。
开单选品把名称拼在一起是为了阅读和插入；档案列表拆开是为了管理和筛选。两套不要混。

## 列表行为

- 数据来自宽表分页检索。档案页是管理，不是开单阅读：产品名 / 品牌 / 规格各占一列（顺序与选品层级相同），禁止再拼成一条全名。
- **筛选做在表头**，不要另做一排筛选按钮。表头输入用采购报价同一套格子（文字 / 清除 × / 下拉），列宽随当前页最长一行撑开、单行完整显示（分类等短列也一样，不要锁死到几个字就裁切）。每一列自己输入：点选档案是标准条件，失焦留下的文字是非标条件，两种都会升到关键词旁边变成可擦掉的条件词，不必先命中档案。表头仍留着当前值，方便接着改；上面擦掉，列上也一起清。
  - 产品名表头输入「20」后失焦 → 条件词「产品名 20」（包含匹配，该列各种名称都显示）；从下拉里点「20热水管」→ 条件锁这一条产品。表头下拉仍是选品那种检索（按关键词、匹配度高的在前），不要收成一条。锁的是**表格数据列**：这一产品下有三条品牌，产品名只在第一条显示，下面两行空着，一眼能看出挂在这个产品下。品牌 / 规格各自是否标准条件，同样只去重这一列。非标条件这一列按模糊匹配，各种名称都显示。
  - 再在品牌表头下拉：选项来自**当前列表**（该条件下面的品牌），不是全局品牌字典。手输品牌名失焦同样升为条件。
  - 规格同理。擦掉规格只清规格；擦掉品牌同时清规格；擦掉产品同时清品牌和规格。
- **全局关键词检索保留**（匹配宽表 keywords，怎么输入都可以）。已有列筛选时，全局检索在这些条件上再过滤，互不抢。关键词、条件词、状态下拉是三个独立控件，高度跟行内小号输入同一套，不要把状态或条件塞进关键词输入框。输入时不打断、不整表转圈，字打完再查。
- 表体不是开单格，也不照抄选品下拉形态。档案框架与选品框架核心相同：点值打开确认浮层、字典检索、改全局；侧重点是已经落在最后一级，格子只显示值。
  - 产品名：点名称打开档案编辑弹窗。
  - 分类 / 品牌 / 规格：没有下拉箭头；点文字直接打开确认浮层。字典类（分类 / 品牌）打开即检索下拉，输入框后面 ▾ 打开字典管理（增删改、引用计数）。可改全局并档。规格是本产品下的名称，纯输入，没有字典管理。
  - 单位 / 售价 / 进价：点开维护浮层。浮层里名称、换算、面价、点位只展示值，点开同一套确认层，不要每行挂常驻输入框。售价与进价同一套列：类型或渠道 | 面价 | 点位 | 实际价。库里存面价和点位，列上用的是乘完的实际价。点位点确认层：确认修改=只改当前这一条规格；改全局=同一品牌+同一分类这一批（售价再加类型，进价再加渠道），不是整个品牌，阀门/电线等其他分类不会被改到。已经单独改过点位的规格不跟着变。列表列只显示实际价，不另开点位列。勾选（默认）与选品同一套——有勾没勾都占位，空行也有；点行切换当前显示项。空行点空位新增。
- 点产品名仍进编辑弹窗。不要用点格子当筛选。
- 表头下拉候选走宽表当前结果（有输入才召回；上级锁定后品牌/规格可空词列出下级），禁止 dump 全库、禁止用全局品牌字典当下拉。
- **单位 / 售价 / 进价列**走同一套关系面板，场景为档案即时写库：改完即调接口并刷新该行，无需整页保存。
- 单位列展示默认显示单位（无则基准单位）；售价列展示默认售价；进价列展示默认进价。空则「未设」。
- 停用产品后搜索默认过滤，可从筛选找回并启用。
- 删除前展示单据引用数；物理删除**允许**（单据行只留快照与 ID，不级联改历史）。现场更稳妥的是停用，停用后检索默认过滤。
- 残缺是连续谱：只填品名也可保存（分类→未分类、规格→通用、单位→件、品牌→普通品牌，补全可感知）。可再打开补任意子集，宽表按已有信息检索。
- 产品级俗称（`product.remark`，如「6分管」）与规格备注（`spec.remark`，这一条的执行标准/企标/国标）分开；品牌没有备注。改规格名立即写库，单位/价格/图片点弹窗底部保存。

## 编辑弹窗行为（范式 B）

一个模态框内并行区块，禁止再叠模态框：

| 区块 | 行为 |
|------|------|
| 产品名 / 分类 / 俗称 | 俗称跟产品名走。分类为全局字典引用：输入检索、失焦匹配或新建 |
| 规格列表 | 同一品牌下多个系列/规格；切换规格加载该规格的单位/价；规格备注跟这一条走（执行标准） |
| 品牌 | 引用全局品牌；本产品可挂多个；改名改的是全局档案。品牌 tab 下不再挂备注 |
| 单位 | 场景为表单本地态：增删改只改弹窗内存，点保存才随整档提交。名称引用全局单位字典。必须有且仅一个基准单位、至多一个显示单位 |
| 售价 / 进价 | 同一套浮层表，挂在「当前规格品牌 × 单位」下；售价按价格类型、进价按供应商；各有一个默认星标 |
| 图片 | 挂当前规格品牌；可设主图 |
| 换算 | 非基准单位填写「1 该单位 = N 基准」 |

保存走整档接口：本地单位列表以 id + unitName + isBase + isDisplay 提交；后端解析全局单位并维护规格引用。保存前走自动补全确认（空分类/品牌/单位按数据层缺省）。

## 与开单共用

开单（采购报价）产品名 / 单位 / 单价走**选用检索**：格子照常打字；顶栏由产品树派生（宽松 + 名称/品牌/规格/执行标准/渠道，默认名称）。词还在格子里，列表换主行粒度。切档是换看法。渠道档问这货谁可能供（已进价 ∪ 经营范围），不是搜供应商档案当产品名。同一串字，切档不改字；匹配是包含与被包含。切档后入口层最左、其余层各占一列；说明默收起。单位列/单价列已经锁规格，不出现这排按钮。规格行与单位层带换算率列。写入单据只走插入按钮；点名称 / 换算率 / 面价 / 点位打开输入浮层再确认（选品面板保持打开）。产品列表与维护浮层走**管理界面**。两套不要换着用——开单插入是选用，维护点行是改档案。全局规则见《档案管理》。现场为什么这样检索：见 `文档可视化/` 指导思想 · 销售开单。

单据行回填必须：标准行单位同时带已加载的单位标识与名称。档案列表即时写接口；编辑弹窗只改内存，点保存才整档提交。
