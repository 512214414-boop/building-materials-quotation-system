## 文档层级与冲突处理

```
项目设计哲学（为什么——约束与权衡）
  ↓
顶层设计规范（设计理念——8 大理念）
  ↓
架构原则（跨功能通用规则——按域 7 份）
  ↓
功能文档（各功能完整自包含——表结构/接口/交互/保存逻辑）
  ↓
技术架构（具体实现——技术栈/部署）
```

**冲突处理**（唯一裁决链，详见[文档编写规范·唯一裁决链](./架构原则/文档编写规范.md)）：用户最新指令 > 项目设计哲学 > 功能文档 > 顶层设计规范 > 架构原则文档。用户最新指令高于一切，指令下达后同步更新所有相关文档。

## 变更记录

- **v16.5（2026-08-11）**：表格列宽彻底固定化——统一 `tableLayout:'fixed'`，列宽 = 设计值（minWidth），内容永不参与列宽计算（用户反馈：点击输入产品规格列"直接变短了"）。**根因**：非虚拟滚动此前用 `tableLayout:'auto'` + `width:'1%'` trick 让列宽"刚好包裹内容"→ 文本态超长内容把列撑开（实测注入超长产品名后产品列 220px→1076px），进入编辑态 input 定宽不撑开 → 列宽回落 220px，用户感知"点击输入列变短"。**修复**：DataViewLayer 虚拟/非虚拟统一 fixed 布局，弹性列不设 width 自动分配剩余空间、wrap 列固定 width=minWidth 换行、普通数据列固定 width=minWidth + nowrap + overflow:hidden（内容溢出裁切兜底，绝不撑开列宽）；补复制 col.width（操作列/序号列此前 width 丢失，fixed 下被均分拉伸）。生产版 8080 实测：采购报价列宽 `[42,32,220,70,80,100,110,140,398]` 三态（文本/超长/编辑）完全一致，产品管理 wrap 列 360px 换行正常，双端回归通过。[表格与交互规范](./架构原则/表格与交互规范.md) v12.1 同步「列宽固定化」规则。
- **v16.4（2026-08-11）**：界面布局框架系统化整理 + 重复实现根治 + 编辑态稳定性收口（用户指令：布局框架缺乏系统性组织、全是补丁式描述；元素"看到多大就是多大"；质疑采购报价未复用抽象组件）。三件事：①**消除 66 个 .js 双实现，`.ts/.tsx` 成为唯一权威源码**（根因核实：早期纯 JS 时代遗留副本在迁移 TS 时未删除；全站 import 统一 `.js` 后缀 + Vite「有真实 .js 就优先加载、没有才回退 .ts」的解析契约 → .js 遮蔽 .ts、类型检查与运行时脱节、改 .ts 不生效——这正是"采购报价改不动、像模仿写的重复代码"的根因。`tsconfig noEmit` 证明 src 下 .js 非编译产物，是历史副本）。删除 src 下 66 个 .js 副本 + 根目录 vite.config.js 双份（备份 `~/Desktop/backup_建材报价系统_前端js清理_20260811`）；`npm run build:check`（check:dupe 源码唯一权威校验 + tsc + vite build）全绿，顺带清零 7 处历史类型错误；防再犯铁律入 [代码与工程规范](./架构原则/代码与工程规范.md)，check:dupe 内置构建（src 出现 .js 即失败）。采购报价产品列/单位列本就复用共享抽象（UnifiedTable/PickerCellEditor/DsInput/FloatPanel/ProductPicker），非重复实现。②**画布模型总纲**：[视觉与布局规范](./架构原则/视觉与布局规范.md) v15.8「画布模型」章节 + [顶层设计规范](./顶层设计规范.md) 理念 1——元素大小 = 真实物理大小（只相对画布）；设备屏幕 = 可视范围（大看全貌小看部分、超出移动画布查看）；CSS zoom 统一缩放（固定步长、界面底部固定按钮、画布内元素同步缩放）；稳定性（状态转换不影响原本大小）。③**编辑态稳定性收口**：激活态输入框从 178px 修复至 206px（收起按钮占位 14→6px）、DsInput embedded 变体统一禁用清除图标（allowClear 占位挤压宽度，单点控制）、缩放控件从右上角移至界面底部右下角。生产版 8080 双端实测：文本态文字 183px / 自由编辑态 212px / 激活态 206px——编辑态绝不变窄；15 管理页 + 8 工作台视图 + 冒烟全量回归通过。
