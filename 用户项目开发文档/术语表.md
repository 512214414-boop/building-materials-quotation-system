# 术语表

> 全系统唯一术语定义处。任何文档引用术语一律「详见《术语表》xx」，禁止本地重新定义。

| 术语 | 定义 |
|------|------|
| 单据 Document | 一笔业务的主记录（documents 表）。开单时抄录客户/产品快照，历史永不变（约束5） |
| 单据行 Document Line | 单据下的明细行（document_lines 表），含产品快照、数量、单价、金额；售价/金额在行上 |
| 8档状态机 | 单据整体进程的 8 个状态，任意双向可逆，唯一权威定义见《单据与状态机》 |
| demand_pending | 需求待确认：单据已建、报价未完成，客户需求明细已录未定稿。进入条件：单据创建（默认态） |
| quote_confirmed | 报价已确认：报价阶段完成，售价已定稿落行。进入条件：报价确认操作 |
| payment_settled | 收款已结算：收款核销完成（paid_amount 达到对账口径）。进入条件：收款核销 |
| allocation_in_progress | 配货进行中：≥此档即可备货/交付履约（交付口径起点）。进入条件：开始配货 |
| delivery_completed | 交付已完成：全部交付已签收。进入条件：签收自动推进 |
| cost_verified | 成本已核定：成本核算完成。进入条件：成本核定确认 |
| after_sales | 售后处理中：存在退换/售后未完结。进入条件：退换登记 |
| archived | 已归档：单据定档归档，只读冻结。进入条件：定档归档 |
| 视图锁 view_locks | documents.view_locks JSON，记录各视图编辑锁定。键名统一 snake_case：payment_reconcile / purchase_quote / delivery / refund_after_sale |
| 标准行 / 非标行 | 已关联产品档案（productId 有值）为标准行；手输文字未关联为非标行。非标行正常保存、正常算金额，仅不带出默认价/单位 |
| 快照 | 业务数据开单时抄录基础档案当时的名称/价格；档案改名/删除不影响历史（约束5） |
| SKU | 规格变体 × 品牌 × 单位 的最小可售/可存单元 |
| 宽表 product_sku_search | SKU 检索扁平宽表，keywords=(产品名+规格+品牌+备注+分类)转小写拼接，FULLTEXT ngram 索引 |
| 缺省值注册表 | 系统补全规则权威定义（规格空→通用、单位空→件、品牌空→普通品牌；默认单位 isDisplay→isBase），见《数据规范》 |
| 画布 | 固定 1200px 设计画布；设备屏幕只是可视范围；CSS zoom 查看层缩放（Chromium 文字等比、Safari 文字不缩放，见《视觉与布局规范》） |
| 令牌 Token | 行高/字号/间距/圆角的唯一参数源，禁止页面写裸值 |
| 三层架构 | 显示层（画）/交互层（输入/焦点/键盘）/业务层（存算），见《表格与交互规范》 |
| 三种交互范式 | 单字段高频→行内+浮动面板；多维矩阵→弹窗表格；父子一对多→抽屉递进 |
| 浮动面板 | 非模态输入辅助，锚定触发元素、水平左对齐不避让、不强制选择、失焦不自动关 |
| 点位规则 | supplier_point_rule：供应商+品牌名+分类名→点位；进价 = 面价 × 点位（无规则默认 1） |
| 成本三段分层 | cost_segment：internal（仓库出库，单价=加权平均进价）/ external_agreed（外部刚需直发）/ external_excess（外部超额入库） |
| 欠库 | 内部出库库存不足时缺口挂 backorders，补货入库自动冲抵 |
| 超额调货 | 订单需求超出部分仅记入最后选定外部供应商，生成待入库单（inbound_tasks），默认入主库房 |
| 权限码 | 导航叶子权限标识，三档 none/ro/rw；唯一清单（17 个）见《系统管理》 |
| 单据编号 | 唯一格式 YY-MM-DD-序号（3位），如 26-08-11-001；权威见《单据与状态机》 |
| 报销副单 | 代采业务报销凭证（reimbursement_bills），业务线归《售后管理》，权限复用 purchase_quote |
| 审计日志 | 关键写操作留痕（audit_logs），含客户/员工名称快照，档案删除不影响展示 |
| 组合去重 | 建档按（无空格产品名+无空格规格）组合值精确比对，命中即复用；候选先索引粗筛压到几百内再打分 |
| 候选集受控 | 规模基线硬性要求：任何"取候选再算"先索引粗筛压到几百内，再应用层精细打分 |
