# 表格与交互规范

> **职责**：跨功能的表格交互通用规则。禁止写组件入参、像素、文件路径。
> 顶层依据：详见《项目设计哲学·约束4》《顶层设计规范·理念4 / 理念8》。
> 产品表结构见《功能文档·产品数据层》；单据行见《功能文档·单据与状态机》；字段下拉如何从关系推导见《实体关系面板体系》；任何档案怎么做见《档案管理》。

## 全文结构

```
├─ 适用
├─ 三种交互范式（数据形态决定载体）
├─ 表格铁律（页面表 / 浮层表）
├─ 录入与选择（自由录入 · 失焦解析 · 选用分离）
```

## 适用

凡列表、单元格录入、贴格展开的辅助面板，一律遵守本文。页面差异只在「列声明 + 场景」，不得自造第二套表格或第二套浮层列表。

## 三种交互范式

数据形态决定载体，不允许凭感觉换壳：

| 形态 | 范式 | 载体 |
|------|------|------|
| 主体单字段、高频改 | 行内编辑 | 页面表单元格直编；关联字段用悬浮定位框辅助，不离开主表 |
| 同一主体多维交叉（产品×规格×品牌×单位×价） | 编辑弹窗 | 一个模态框内表格化分区，事务一次提交；弹窗内禁止再叠模态框 |
| 父 + 独立子实体列表 | 整页下钻 | 同一区域换成子表 + 顶部上下文；禁用抽屉切换层级 |

判定：先看是否「父+独立子列表」→ 下钻；再看是否多对多交叉矩阵 → 弹窗；否则行内。

## 表格铁律

全系统只允许两类表，职责互不侵占：

- **页面表**：承载业务主列表（产品档案、单据行、客户/供应商列表）。实现只许 `UnifiedTable`。统一行高、字号、末尾空行、操作列固定在首列。工作台单据表走点值确认层（确认才写，取消不写），不要格子失焦保存。废弃的 `DsTable` 已删除，禁止再引入第二套页面表。
- **浮层表**：承载贴格展开的关系子集（单位 / 售价 / 进价 / 字典 / 联系信息）。表头 + 数据行 + 末尾空行；宽度随内容撑开。禁止为某一字段再写一套列渲染。弹窗里的分类 / 名称 / 规格 / 备注 / 单位，以及分类管理面板里的搜索、新增、改名，跟检索框同一套小号输入，不要有的高有的矮。

列宽只走统一预设；新代码禁止页面级裸数字最小宽度。数字列用普通输入，不用原生数字控件。

**显示与编辑同一套度量**：状态转换（点开确认层）不得改变单元格原本大小。工作台短字段（数量、单价、单位、备注）和产品名一样是点值格：格子只展示，点开确认层再输入。数据列默认单行、列宽随当前页最长一行撑开，完整显示，禁止省略号截断。格内为文字 / 清除 / 待确认，互不重叠。贴格面板只叠加在格子外。

档案列表按管理拆列（产品名 / 品牌 / 规格，顺序与选品层级相同）。**每个档案列表必须有名称主标识列**：点击打开完整编辑弹窗（该主体全部字段，含一对多矩阵、末尾空行可追加）。这不是产品/供应商私有，库房/客户同一槽。禁止再给人填业务编码（身份用数据库主键）。筛在表头里输入：点选档案是标准条件，失焦留下的文字是非标条件，两种都升到关键词旁边变成独立条件词（可单独擦掉），不要塞进检索框，状态下拉也是独立按钮。表头仍留着当前值，方便接着改；擦掉则两边一起清。表头下拉是选品那种检索（关键词、匹配度高的在前）。点选标准条件后，**表格该列**同一组只在第一条显示名称，其余行空着，不是把下拉收成一条；非标条件这一列各种匹配都显示。下级从当前结果里再选。表头筛选用同一套格子输入（文字 / 清除 × / 下拉），列宽随当前页最长一行撑开、单行完整显示（分类等短列也按最长内容撑开）。

工作台单据表同一套表头筛：复用 HeaderCascadeFilter，选项来自**当前单据所有行**，不是全局档案。级联粒度产品→品牌→规格。条件升到业务条旁 chip，表头仍留当前值。筛只改变眼前能看见的行，不改整单合计；空行仍在表底可录入。不要套 ArchiveListPage。

选品框架与档案框架核心相同、侧重点不同：选品要层级展开和插入；档案已经是最后一级，格子用值，点文字即改。开单表对齐档案值：点值打开确认浮层，确认才写。选用检索挂在确认层输入上。选品面板和打印纸把名称拼在一起方便阅读；工作台表按产品名 / 品牌 / 规格拆列，方便表头级联翻找。

**勾选与操作列**：行上的扩展按钮只操作**当前行**。表头同一位置的扩展按钮操作**已勾选行**（没有勾选则该项不可用），或整表范围的整理类动作。勾选相关的批量按钮禁止再放到工具栏。空行不勾选、不出现行菜单。有勾选就必须能从报头扩展菜单做对应批量动作。

## 录入与选择

```
├─ 为什么存在：用户是 Excel 习惯——先敲字、后核对，不能被检索框抢走焦点
│   ├─ 自由录入优先：输入过程只检索展示，不写库；失焦 / Enter 才解析关联
│   ├─ 选品选用检索：下拉面板顶栏由树派生（宽松 + 各层精准）。格子只负责打字。同一串字，切档不改字。匹配是包含与被包含。到那一层有什么就搜什么，检索是全的，不按词禁结果。点一下用当前词重打，列表换主行粒度。单位列/单价列不出现这排按钮。详见《档案管理·选用检索》
│   ├─ 选品内改档案：格子划过要看得出能点（原常驻输入那套 hover，手型）。点开输入浮层（看全文 + 影响范围）。字典格检索下拉选已有项；输入框后面 ▾ 打开字典管理（增删改），给没有独立字典页的字段用。默认确认修改=只改当前（不列清单）；单位/品牌/分类/售价类型/供应商可再点「改全局」（并档并列出影响数据）。点位「改全局」改当前品牌+当前分类这一批，已经单独改过的规格不跟着变。规格行与单位层有换算率列（品牌+规格+单位；基准固定 1）。选品主面板保持打开；取消即恢复；不在窄列里改、不留半改确认钮
│   ├─ 边用边扩充：使用点就能补档案，补完立即可用；禁止「只能去档案页新建」。A 类字典录入/挂载场景 allowCreate=true，按名称确保幂等 → 直接建即选 + reused 可感知提示，无二次确认；列表列筛 allowCreate=false
│   ├─ 确认策略三档（槽位内置）：单字段幂等=直接建即选；多字段+缺省值+宽表去重+相似匹配=二次确认弹窗（产品特例）；改全局/删除=二次确认+列出影响范围（并档/引用计数）
│   ├─ 源格高亮：确认层从某格展开时，源格加 active 状态（边框/底色），视觉上一眼看出确认层从它展开；close 即清
│   ├─ 展开钮高亮：选用检索展开/收起钮、字典管理钮在展开态时图标高亮（主色/底色），新用户一眼看出按钮与展开面板的关系，不靠位置记忆
│   ├─ 显式选用：单据引用场景回填宿主行只走插入按钮，与面板内点名称改档案分开
│   └─ 未关联档案的行照常保存、照常算金额（非标行不是错误行）
├─ 空行
│   ├─ 页面表底部常驻空行；翻页场景空行按所在位置插入，禁止甩到末页
│   └─ 点选匹配命中后抑制失焦二次提交，避免一条输入变两行
├─ 危险操作
│   └─ 删除 / 停用 / 会清空下级配置的动作二次确认
└─ 悬浮定位框（输入辅助，不抢主体）
    ├─ 非模态、失焦不自动关、没选中也保留自由文字
    ├─ 移动画布 / 手指滑动不关（手机屏窄就是靠挪画布看完选品）；点一下空白才关
    ├─ 开单格点一下进确认层，确认层真输入同一手势出键盘（数量/备注也是；未编辑不得 readOnly）
    ├─ 限高纵向滚；横向完整显示列，禁止面板内横滚
    ├─ 确认/取消钉在面板底栏（FloatPanel footer），不跟内容滚；误触打开也能立刻关掉
    ├─ 确认层说明换行，宽度走列宽预设，不按整句把面板撑开
    ├─ 确认层变化对比：原值弱灰卡片、新值品牌绿卡片，中间 →；禁止用「」把一对值包成一行字。未改不显示这对卡片。范围说明另起一行弱字
    ├─ 水平左对齐锚点，不做视口避让；左右夹在 1200px 画布内（贴右边打开时在画布里平移）。仍超出视口靠移动画布看
    ├─ 浮层/弹窗住在画布舞台叠加层里，跟画面远程桌面式等比缩放（字号间距一起缩）；锚点空隙也跟 zoom 等比。少留白，宽度吃内容。禁止为手机改全屏 / 媒体查询重排。禁止浮层逃出舞台再补 zoom
    └─ 派发：只提示 → 消息通知；填表交付 → 模态框；贴元素辅助 → 悬浮定位框。禁止第四种浮层
- **单输入框清除**：全站与采购报价「客户」输入框同一套——有值且悬停/聚焦时显示纯文本 ×，不换圆形图标、不撑高、不另写一套清除。表格格内输入同样如此。
```

## 反模式

- 页面自写单位面板、价格面板、字典列表，或在页面里堆像素样式。
- 输入一个字就绑定外键；点选匹配后又用失焦文本再提交一次。
- 标准行提交单位时只有名称没有真实单位身份（必须同时具备已加载的单位标识与名称）。
- 用抽屉做下钻；在编辑弹窗上再叠一个模态框。
- 把矩阵类维护面板做成与浮层表并列的第二套基座。
- 把开单选品 / 选单位的**选用列表**换成单位维护矩阵（呈现与点选行为都会变）。
- 选品点整行插入，同时又点名称编辑（焦点和点击会打架；回填只走插入按钮）。
- 已开单据行按关联 ID 自动去档案里刷名称（快照只在再插入 / 换绑产品时重抄；改数量、改单价、只换单位都不刷产品名）。
- 页面表默认打开勾选却没有表头批量入口；或空行也能勾选 / 插入 / 删除。
- 把勾选后的批量删除等动作放到工具栏，而不是表头扩展按钮。
- 确认层挂选用检索定位不稳：确认层 FloatPanel 展开并定位稳定后，选用检索子层才从确认层输入框展开（锚定输入框），保持「格子→确认层→选用检索」定位链，禁止确认层未定位好就展开子层导致跳动。
- 确认层选用检索无主动收起钮：确认层输入框带选用检索的主动展开/收起钮（与表格中行为一致，只是移到确认层），列表默认常开可手动收起。
- 确认层两个下拉撞脸：确认层输入框旁若同时有「选用检索展开」与「字典管理」两个按钮，必须靠图标语义区分（选用检索=列表/放大镜图标，字典管理=齿轮），禁止两个长一样的下拉。
- 确认层变化对比用「」包值：原值/新值必须能靠颜色和卡片分清（C70），禁止写成「旧」→「新」纯文本。未改不显示。新建候选把关键词做成卡片，不要写成新建「某某」。
- 确认层每格都要点确认再关：启用邻格快切的表格，切换即提交当前格并打开下一格确认层（底栏方向钮或键盘 Tab/Shift+Tab 横移、↑↓ 纵移），Enter 仍为确认并关闭。未启用处不变。
