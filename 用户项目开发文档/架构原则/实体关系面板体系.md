# 实体关系面板体系

> **职责**：全系统「表格字段下拉 / 档案维护浮层」如何从数据关系推导出来——边用边扩充、三场景、读路径与写路径。不写组件入参、不写文件树、不写迁移清单。
> 顶层依据：详见《顶层设计规范·理念4 / 理念8》《架构原则·表格与交互规范》《架构原则·档案管理》。
> 表结构权威：《功能文档·产品数据层》。

## 全文结构

```
├─ 中心思想：边用边扩充
├─ 三场景（档案即时 / 表单本地 / 单据选用）
├─ 读路径（记录 → 关系 → 面板模型 → 浮层表）
└─ 写路径（解析 → 分发 → 变更路由）
```

## 中心思想：边用边扩充

档案不是上线前一次录完的。开单和维护产品时会不断碰到「字典里没有的单位 / 价格类型 / 供应商」。若只能去档案页补数据，流式录入被打断；若输入框只能选不能建，非标文字无法归集。

| 原则 | 含义 |
|------|------|
| 边用边扩充 | 任何使用点都能补档案，补完立即可用 |
| 输入不阻塞 | 选用时输入中只检索；失焦 / Enter 才解析关联。选品里改档案不靠失焦保存 |
| 显式选用 | 单据回填宿主行只走插入按钮，与面板内编辑分离 |
| 改档案先确认 | 选品列窄、看不全，不在格子里改。格子划过要看得出能点。点开输入浮层：看全文 + 影响范围。原值/新值用卡片对（原弱、新强、中间 →），不要「」包成一句。字典格打开即检索下拉选已有项；输入框后面 ▾ 打开字典管理（增删改），给没有独立字典页的字段用。默认「确认修改」只改当前这条；单位 / 品牌 / 分类 / 售价类型 / 供应商另有「改全局」（并档并列出影响数据）。点位另有「改全局」：当前品牌+当前分类这一批（售价=类型+品牌+分类，进价=渠道+品牌+分类），已经单独改过的规格不跟着变，确认层列出跟圈组会被改到的规格。换算率是单位旁的值，只改当前规格×品牌×单位。取消即恢复。确认层挂在当前选品层下，不得把选品主面板关掉。档案列表没有浮层父级时，确认层自己作为一级打开。检索下拉、字典管理都是确认层的子槽，层级按父子自动叠，不要写死数字。维护浮层（单位 / 售价 / 进价）格子同样只展示值：售价与进价同一套列（类型或渠道 | 面价 | 点位 | 实际价），点开同一套确认层，不要每行挂常驻输入框。档案列表不另开点位列。勾选位与选品对齐：空行也占位 |
| 读写同构 | 同一套浮层表与同一套变更路由；差异只是场景 |
| 一层一个真相源 | 面板列结构只从实体关系登记表推导，禁止按字段名手写第二套列 |

目标效果：格子里输入「米」→ 看到候选 → 失焦匹配已有或快速新建 → 外键写入 → 表刷新；单据里点插入只回填当前行。选品里改档案点开输入浮层看全再确认，取消即恢复；已开单据行的快照不自动跟，再插入才换成新内容。改数量 / 换单位不会按关联去刷产品名。

## 三场景

| 场景 | 用在哪 | 写到哪 | 选用列 |
|------|--------|--------|--------|
| 档案即时 | 产品列表等档案页 | 立刻调接口，成功后刷新宿主 | 无 |
| 表单本地 | 产品编辑弹窗 | 只改弹窗内存，点保存才整档提交 | 无 |
| 单据引用 | 采购报价等单据行 | 维护子集仍走变更路由；回填行只走选用 | 必须有 |

冲突时以「链路是否打通」为准，不以某一页的特例分支为准。

常见断点（实施时必须整链自检）：换绑单位只加不删导致重复行；表单补丁改了行键却没迁移换算；解除规格引用时误删全局单位；未匹配只亮图标、保存前没有新建兜底；某处仍在输入过程中直接写库。

## 读路径

从当前行记录推出该显示哪张浮层表，禁止页面手写列。每一层浮层表都有列头（规格 / 单位 / 售价 / 进价，或售价类型 / 面价 / 点位），数字才知道是哪一列。浮层限高只纵向滚，横向把列一次铺开，禁止面板里再横滚一遍才能看展开。确认/取消钉在面板底栏，不跟说明文字一起滚。水平左对齐锚点，不做视口避让；左右不得画出 1200px 画布，贴右边格子打开时在画布里平移。仍超出视口靠移动画布看；挪画布或手指滑动不关浮层，点一下空白才关。

点位关系（与 `文档可视化/` 同一口径）：面价跟单位走，点位跟圈组走。确认修改 = 当前这一条规格；改全局 = 当前品牌 + 当前分类这一批（售价再锁类型，进价再锁渠道）。已经单独改过的规格不跟着变。列表 / 选品 / 开单显示实际价。

```
当前行记录
  → 解析实体上下文（本行是 SKU / 规格单位 / 售价 / 进价 / 字典项）
  → 查实体关系登记表（父子、字典引用、子集）
  → 推导面板模型（列、空行、能否增删、场景截断）
  → 拼出浮层表的行
  → 唯一浮层表渲染（少留白；跟画布 zoom 等比）
```

登记表按「边用边扩充」增长：先登记产品域（规格单位、售价、进价、全局字典），其他域需要同一交互时再登记，不预造空壳。

上下文截断：单据行只有规格品牌时，单位面板只展开该规格已引用的单位；名称和单位都定了，单价下拉只展开该单位的售价/进价。采购报价产品名 / 单位 / 单价三列共用选品框架，差异只是检索主行放哪一层。没有父上下文时，退化为全局字典或常见单位，不得假装有子集。

## 写路径

```
输入文本 / 点选 / 绑定列 / 选用列
  → 字典解析（精确匹配 / 新建 / 未匹配 / 改名）
  → 分发（绑定、改名、忽略、未匹配标记）
  → 变更路由
        ├─ 档案即时 → 接口 → 刷新
        ├─ 表单本地 → 本地补丁（换绑要迁移关联键）
        └─ 单据选用 → 只回填宿主，不经字典解析
```

标准行选用单位时，回填必须同时带**已加载的单位标识 + 名称**；缺标识视为未就绪，拒绝提交（避免把残缺默认单位写进单据）。点选匹配命中后抑制失焦文本二次提交。

未匹配：格子可保留自由文字并标记待确认；整档或整单保存前按缺省值注册表做快速新建兜底，禁止只显示图标就结束。

## 统一实体关系模型槽位（数据关系图驱动）

带数据表的功能 = 一份「数据关系图」参数（父子 + 字典引用 + 子集 + 上下文依赖 + 确认策略），扔进槽位自动产出五个面。新增功能只填这一份，禁止各视图手写第二套列、第二套快建、第二套确认。

| 面 | 槽位自动产出 |
|----|------------|
| 表格 UI | 主表+浮层表列结构从实体关系推导：列序跟数据模型走（分类→产品名→品牌→系列/规格→单位→售价→进价→备注），列宽/对齐/单元格类型/能否点/布局都由字段元数据决定。走 `entityRelations` 登记表 + `deriveTableColumns` 推导引擎，禁止各视图手写第二套列 |
| 检索 | 选用检索顶栏由关系树派生（宽松+精准），走 `pickerTree` |
| 字典快建/管理 | A 类字典录入/挂载场景 `allowCreate=true`（边用边建）：按名称确保幂等 → 直接建即选 + reused 可感知提示，无二次确认。管理面板（▾）增删改 + 引用计数。列表列筛 `allowCreate=false` |
| 确认策略 | 槽位内置三档：单字段幂等=直接建即选；多字段+缺省值+宽表去重+相似匹配=二次确认弹窗（产品特例）；改全局/删除=二次确认+列出影响范围（并档/引用计数） |
| 场景截断 | 同一棵关系树，档案/工作台/库存取不同子集（哪些列、能否编辑、空行规则） |

两类字段由数据关系图区分（槽位自动选，不各处自写分支）：

- **A 类·纯全局字典**：关系图=单层（name 全局唯一，无父依赖）→ 走 DictSlot（检索+快建+管理面板）。分类/品牌/价格类型/联系方式/客户类型/地址类型/单位全局字典。
- **B 类·挂上下文关联**：关系图=父实体→子表（必须带父 id 才能建）→ 专用 Picker，管理在父实体编辑内。spec_unit(标准单位)/product_brand/spec。
- **单位=A+B 混合**：非标行（无 specId）走 A 类全局 unit 字典；标准行（有 specId）走 B 类 spec_unit。槽位按「关系图+当前有无父 id」自动选，不在 UnitPicker 里揉两套。

视觉：确认层从某格展开时，源格加 active 状态（边框/底色），close 即清；选用检索展开/收起钮、字典管理钮在展开态时图标高亮，新用户一眼看出按钮与展开面板的关系。

落地文件：登记表 `frontend/src/shared/config/entityRelations.ts`（实体/字段/关系/场景可见性 真相源）+ 推导引擎 `frontend/src/shared/config/deriveTableColumns.ts`（`deriveTableColumns` 产骨架 + `mergeColumns` 合并视图专属 render，支持 slot 插入动态展开列）。已迁移视图：采购报价（workbench）/ 产品档案（archive，含 skuPrice slot）/ 库存主表（inventory）。改列序只改登记表，视图自动跟。

图形化说明：可视化文档侧栏「实体关系槽位 · 实体关系槽位模型」一章，把模型形状（一进五出）、示例登记表（product workbench 字段）、关系怎么插/模型怎么解读、槽位机制（骨架+override+slot）画成树与表，不靠文字脑补。

## 反模式

- 为售价、进价、单位各写一套**网格 DOM**（应走 EntityPanel 基座）。
- 用字段名分支代替关系登记表。
- 把开单**选用**（ProductPicker / UnitPicker）换成单位维护矩阵，或反过来用维护面板点行即插入。
- 解除规格对单位的引用时删除全局单位字典行。
- 浮层按视口左右避让（手机和电脑位置会不一致）；或左右画出 1200px 画布。
- 滑动画布或锚点滚出屏幕就关掉选品（手机屏窄就是靠挪画布看完）。
- 开单格未编辑时 readOnly，或先画 span 再异步 focus，导致手机点格不出系统键盘。
