# 导航与路由规范

> **适用**：设计或修改任何导航路径声明、路由注册、位置记忆、底部操作上下文栏、多视图切换保活。改导航前先读本文档。
> **定位**：全系统导航与路由域的**知识库条目**。只讲跨功能通用规则，不写实现细节（代码文件、组件由代码承载，见[文档编写规范](./文档编写规范.md)）。
> **顶层依据**：项目设计哲学（原则 2 分层隔离、原则 5 约定大于配置）→ 顶层设计规范（理念 3 骨架层级固定、理念 7 导航按钮统一）。
> **关联文档**：外观参数见 [视觉与布局规范](./视觉与布局规范.md)；权限设计见 [权限与职责规范](./权限与职责规范.md)。

## 全文结构（一眼看全貌）

```
约定大于配置（原则5：文件放对位置就自动出现，不用手动登记）
  ↓
导航路径声明（"一级.二级.三级"）→ 自动注册 → 层级自动生成 → 权限树同构
  ↓
用户不想每次回来都从头开始 → 位置记忆（回访还原）
  ↓
顶栏管"去哪"、底栏管"退与进" → 分工 + 底部操作上下文栏（浏览栈）
  ↓
切视图卡顿、状态丢失 → 视图级保活（懒激活 + 显示隐藏切换）
```

## 导航声明与自动注册：约定大于配置

每个功能模块必须声明自己的导航路径，权限依据导航路径生成树形权限集。

### 声明格式

**`一级导航名.二级导航名.三级导航名.……`**，导航顺序按分隔符从前往后依次递增（示例：`订单中心.订单协同工作台.收款对账` → 订单中心=一级、订单协同工作台=二级、收款对账=三级）。

### 层级生成

```
├─ 一二级导航：界面固定布局框架，由布局渲染（顶栏一级、二级导航行）
└─ 三级及更深：层级不设上限，由布局框架自动生成
    └─ 自动插入在二级导航与页面内容区域之间——不得塞进内容区当普通工具条
```

### 注册表机制

- 各功能模块在自己的入口文件中声明导航路径，由全局导航注册表统一汇总（员工端与客户端各自独立注册表）。
- 每个导航节点声明：路径、显示名、入口路由、默认进入路由、图标（可选）、权限标识。
- **与权限的关系**：导航层级 = 权限树层级；一二级控制进入模块/页面，三级及更深的叶子控制具体视图。入口一律展示，无权限时在内容区提示（见[权限与职责规范](./权限与职责规范.md)）。

### 文档维护规则

本文档只约束导航路径声明与自动注册机制，不展开具体功能的导航路径清单——各功能文档自包含定义本功能的导航路径声明。代码与文档必须同步。

## 位置记忆：回来时还是离开时的样子

**问题**：一级/二级导航若每次都跳模块"默认首页"，且路由切换会卸载页面，用户会感觉"全部重新进入"，离开前的单据、视图、列表位置都丢了。

```
├─ 回访还原：再次点击某一级/二级导航 → 优先进入该节点「上次离开时的完整地址」，而不是永远回默认首页
├─ 无记忆才回落：该节点从未访问过 → 才用注册表的默认入口
├─ 离开即记账：只要路由变化 → 把当前完整地址记到对应一级、二级节点下
├─ 工作台特例：无单据 id 进入工作台 → 优先打开本会话已打开标签中的当前单据，而不是总拉列表第一张
└─ 权限不变：记忆地址仍走原有鉴权，无权限则进无权限提示
```

**不做（当前阶段）**：不在布局层做整页缓存（隐藏缓存整页）。列表筛选项等页面内状态由各页按需存；导航层只保证"回到哪个 URL"。

### 多视图切换保活

导航层不做整页缓存；但「同一页面内部的多个业务视图」切换属于页面内部行为，可以做**视图级保活**：

```
├─ 懒激活：视图首次访问才挂载——避免初始全量挂载
└─ 显示/隐藏切换：已访问过的视图保持挂载、用显示/隐藏切换而非卸载销毁
    └─ 切回零延迟、状态全部保留、无重新加载
```

## 底部操作上下文栏：底栏管"退与进"

员工端**页面级**能力（挂在布局，不是某个业务页私有）：**顶栏管「去哪」，底栏管「操作轨迹上的退与进」。**

**一句话**：固定悬浮在员工端底部；记录你在系统里走过的每一步；上一步 / 前进一步面向整站，不绑定工作台。

### 放什么

| 适合 | 不适合 |
|------|--------|
| 上一步（回到上一地址：含各级导航、视图参数、单据 id） | 「返回某某清单」等业务专用文案（应靠上一步自然退回） |
| 前进一步 | 单据字段、模块导航 |
| 撤销编辑（有编辑栈后再亮） | 仅某一视图才有的业务主按钮 |
| 轻量状态提示 | — |

### 怎么放

```
├─ 挂在员工端布局，登录后所有员工页共用；登录页不出现
├─ 固定贴视口底部，内容区预留等高占位
├─ 自建页面浏览栈：正常跳转压栈；点上一步/前进时出栈并跳转，不再重复压栈；登出清空浏览栈
└─ 与「位置记忆」不同：记忆是回访模块时还原；本栏是当前会话操作序列的后退/前进
```

### 自检

- [ ] 从清单 → 工作台 → 改视图 → 点「上一步」，是否按操作顺序退回？
- [ ] 跨模块跳转，底栏是否仍在、能否后退？
- [ ] 底栏是否误做成"仅工作台才有"？（不应）

## 顶栏与底栏分工

- **顶栏**：去哪个模块 / 子功能 / 业务视图。
- **底栏**：刚才那一步能不能退、退完能不能再进。
- 工作台单据标签行：多单据切换，不塞返回按钮。
