## 需求概要（用户原话意图 + 已确认口径）

### 一、表格 UI 分层架构缺陷评审与修复

对真相源条目 `ui-layer-model`（表格 UI 分层五层模型）做架构级评审，修复已核实的 6 处缺陷，保证「架构设计必须是最优方式」：

| # | 缺陷 | 修复方向 |
| --- | --- | --- |
| 1 | L4 `editEntry` 保留 `inline` 常驻输入分支，与硬纪律「禁止常驻输入框（全局已取消）」直接冲突 | 删除 inline，editEntry 收为 none / confirm / link / expand 四态 |
| 2 | L4 三维参数与 `entity-meta.yml` 的 `pages.slots` 是两套声明风险（v31 页面装配器已由登记表驱动列顺序） | 补裁决规则：L4 三维参数声明落点 = entity-meta.yml pages 段，与 slots 同处登记，页面只装配，禁止第二套声明 |
| 3 | 「20 页 135 处 custom」现状数字手写进真相源，会漂移 | 补规则：现状统计以 `auditCellSpecs` 等脚本实测为准，不手写数字 |
| 4 | 装配序列表与旧提案不一致（旧提案采购报价/售后带「主表行」，真相源没有） | 对代码核实（UnifiedTable 实际使用页），按裁决链定对错 |
| 5 | `ViewFrame.tsx` 注释 actionBar 标「L3」、bizStrip 标「L2」，与五层模型层号冲突 | 代码注释对齐真相源（两者同为 L2 行槽位层） |
| 6 | 矩阵归属裁决（MatrixTable 与 UnifiedTable 并列引擎 `engine: 'matrix'`）未登记真相源 | 补记裁决 |


### 二、旧文档退役：吸收→删除，保证文档唯一性

- `用户项目开发文档/`（33 个 md + 2 个 xlsx 业务资料）停止维护，不再作为规范源
- **全量盘点 + 首轮删除**（用户已确认）：一次盘点全部 33 个文件并定级；AI 逐文件判定融入状态，已确认融入的直接删（git rm 可回滚），独有内容登记待吸收清单后续慢慢清
- 建立「旧文档退役吸收台账」，每个删除文件记录删除理由与融入去向（可视化哪一篇）
- 随进度逐步吸收清除，最终消灭重复，保证项目文档唯一真相源 = `文档可视化/data-source/methodology.yml`

## 技术方案

### 真相源机制（既有，直接复用）

- 唯一规范源 = `文档可视化/data-source/methodology.yml`；改动只改 yml 一处，跑 `node tools/gen-docs.mjs` 自动重生成 `js/data/gen/35-ui-layer-model.js`、AGENTS.md GEN 节、index.html 装配清单——禁止手改生成物
- 新增「旧文档退役」章不新开篇章：退役台账落在 `docs-coverage.md`（既有台账机制），不进真相源（属项目过程记录，非方法论）

### 缺陷修复落点

- 真相源 `methodology.yml` 条目 `ui-layer-model`（约 2897–2997 行）：
- L4 三维表：删 `inline` 分支行，editEntry 改四态，同步 lead/facts/rules 中相关表述
- rules 追加三条：①L4 声明落点=登记表 pages 段（第二套声明=违规）；②现状数字以脚本实测为准；③矩阵归属=并列引擎裁决
- 装配序列表先对代码核实（grep UnifiedTable 使用页的行结构）再改
- `frontend/src/shared/components/ViewFrame.tsx`：仅改 42/44 行注释层号（L3→L2 统一），零逻辑改动，不需要重新 build（纯注释）

### 旧文档盘点方法

- 分批读 33 个 md（用 code-explorer 子代理按组并行：架构原则 13 / 功能文档 11 / 根目录 6 / 技术架构 2 / AI协作 1），逐文件产出四定级：
- **A 已融入可删**：内容已在真相源对应篇，头部已标规范化（如 表格UI分层抽象提案.md）
- **B 有独有内容待吸收**：先吸收进真相源对应篇（或登记待吸收清单），吸收后再删
- **C 过时作废直接删**：与现行裁决链冲突、且无可回收内容
- **D 保留**：xlsx 业务资料、仍在用的数据文件
- 删除统一走 `git rm`，可从 git 历史恢复

### 性能与可靠性

- 全程 git 按逻辑分开提交：fix(真相源缺陷) / chore(注释对齐) / chore(旧文档清理) 三个以上独立 commit
- 收尾自检：`node tools/gen-docs.mjs` 重跑无 diff 残留 + `node tools/check-docs.mjs` 通过
