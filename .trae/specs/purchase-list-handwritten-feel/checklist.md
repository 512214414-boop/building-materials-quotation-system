# 采购清单手写单据式录入体验优化 验收清单

## 虚拟滚动验收

- [ ] 50 行数据：DOM 中 `<tr>` 节点数 ≤ 30
- [ ] 100 行数据：DOM 中 `<tr>` 节点数 ≤ 30
- [ ] 200 行数据：DOM 中 `<tr>` 节点数 ≤ 30
- [ ] 500 行数据：DOM 中 `<tr>` 节点数 ≤ 30
- [ ] 滚动时节点动态替换（非移动）
- [ ] 滚动流畅，FPS ≥ 55（使用 Performance 面板验证）
- [ ] 虚拟滚动与分页共存正常（翻页后滚动重置到顶部）

## 样式一致性验收

- [ ] `CELL_SHARED_STYLE` 包含 `boxSizing: 'border-box'`
- [ ] `CELL_TEXT_STYLE` 和 `CELL_INPUT_STYLE` 完全继承字体度量（font-size/line-height/font-family/font-weight/letter-spacing）
- [ ] 文本态 `<div>` 和编辑态 `<input>` 的 computed style 完全一致（padding/border/margin/font-*）
- [ ] 焦点态仅添加 `box-shadow: inset 0 -1px 0 var(--brand-primary)`，不改变其他样式
- [ ] 点击单元格时文字无位移（使用浏览器开发者工具检查位置坐标）
- [ ] 点击单元格时文字无闪烁（肉眼观察）
- [ ] 点击单元格时文字无大小变化（使用浏览器开发者工具检查 computed style）
- [ ] 失焦后切换回文本态无视觉跳动

## 渲染优化验收

- [ ] `mergedColumns` 使用 `useMemo` 缓存，依赖项正确
- [ ] 行渲染使用 `React.memo` 优化
- [ ] 编辑态切换仅触发目标单元格重渲染（使用 React DevTools 验证）
- [ ] 其他单元格不重渲染

## 性能验收

- [ ] 50 行数据：首次渲染耗时 < 100ms
- [ ] 100 行数据：首次渲染耗时 < 100ms
- [ ] 200 行数据：首次渲染耗时 < 100ms
- [ ] 500 行数据：首次渲染耗时 < 100ms
- [ ] 点击编辑响应时间 < 50ms
- [ ] 滚动时帧率 ≥ 55 FPS

- [ ] 键盘导航：Enter 键提交并移至下一行同列
