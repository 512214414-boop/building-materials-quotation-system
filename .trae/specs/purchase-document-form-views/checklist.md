# Checklist

## 顶层设计与架构（v2）

- [ ] 方案明确采购清单默认单据视图，表格视图为高级批量操作备用
- [ ] 数据层保持不变（documents + document_lines），无需改表结构
- [ ] 视图层提供单据视图与表格视图两种平行视图
- [ ] 单据视图采用「纸面工作区」概念，支持连续预览（默认）和单页聚焦两种浏览模式
- [ ] 模板层提供 A4 竖版、A5 横版、A5 竖版三种真实纸张规格，尺寸 1:1 渲染
- [ ] 屏幕所见即打印所得（WYSIWYG）

## 模板与渲染

- [ ] A4 竖版模板（794×1123px）：约 25-28 行，含抬头/页眉两行/七列表体/页脚（总计+大写/小计/提示/地址电话/制单人/页码）
- [ ] A5 横版模板（794×559px）：约 10-12 行，右上角屏幕操作区（打印隐藏），右侧竖排经营范围宣传区（打印保留），长文本折行
- [ ] A5 竖版模板（559×794px）：约 16-18 行，客户信息纵向排列，含收货单位签字栏
- [ ] 三种模板空白行补满显示「—」占位，任意空白行可点击录入
- [ ] 字段映射完整：页眉（单号/客户/日期/备注/地址/电话）、表体（序号/产品/数量/单位/单价/金额/备注）、页脚（总计/大写/小计/提示/地址/电话/制单人/签字栏/页码）
- [ ] 客户端单据抬头为「采购清单/订货单」，员工端为「销货单/配送单」
- [ ] 页脚页码居中显示「第X页/共X页」，每页重复页眉页脚

## 视图切换与工具栏

- [ ] 主切换栏（ViewFrame actionBar）只放「单据视图」「表格视图」两个按钮
- [ ] 单据内工具栏提供：模板切换（A4/A5横/A5竖）、浏览模式切换（连续/单页）、打印预览、打印
- [ ] 采购清单默认进入单据视图，首次 A5 竖版+连续预览模式
- [ ] 视图/模板/浏览模式偏好记忆到 localStorage
- [ ] 切换视图/模板/浏览模式时不重新请求后端
- [ ] 表格视图完整保留为备用，所有现有功能不受影响
- [ ] 员工端采购报价视图同样支持单据视图

## 分页与浏览模式

- [ ] 连续预览模式：多页垂直排列，页间距 16px，滚动查看，像 Word 打印预览
- [ ] 单页聚焦模式：当前页居中，上一页/下一页按钮，页码导航
- [ ] 连续→单页切换时以当前滚动位置最近页为当前页
- [ ] 单页→连续切换时滚动到之前的当前页
- [ ] 下一页永不禁用，可随时跳到空白页录入
- [ ] 当前页所有行填满时自动追加新页
- [ ] 序号全局连续，不因翻页重置
- [ ] 连续预览模式下视口外 2 屏页面懒渲染占位，20 页以内全量渲染

## 编辑交互

- [ ] 任意单元格（数量/单价/备注/产品信息等）点击进入编辑态
- [ ] 编辑态使用 DsInput variant="plain"，尺寸与文本态一致无跳动
- [ ] Enter/Tab/失焦提交，Escape 回滚，Tab 支持同页跨单元格跳转
- [ ] 产品信息点击弹出 ProductPicker，面板 getPopupContainer 指向 .app-container
- [ ] 单位/价格单元格点击触发 UnitPriceExpandPanel，portal 到 app-container 不被裁剪
- [ ] 浮层面板复用 FloatPanel + PanelTree 级联关闭机制
- [ ] 任意空白行点击即可开始输入，不限最后一行；填满自动追加新页
- [ ] 行内更多菜单支持删除行，删除后自动调整页码
- [ ] 无权限字段显示为静态文本只读，不隐藏任何元素
- [ ] 保存成功：行内绿勾一闪 + message.success（固定key去重）
- [ ] 保存失败：行内红叹号 + message.error + 显式 refresh/loadById，禁止 remount
- [ ] 非标产品数据显示 InfoCircleOutlined 待确认标记

## 打印输出

- [ ] 单据内工具栏提供「打印」按钮
- [ ] 「打印预览」模式：屏幕上隐藏所有编辑UI（工具栏/更多菜单/输入框边框），显示纯净纸张
- [ ] `@media print` 隐藏 AppShell/操作栏/工具栏/编辑UI
- [ ] `@page size` 跟随当前模板（A4 / A5 landscape / A5 portrait）
- [ ] 多页每页 page-break-after: always，页眉页脚重复
- [ ] 打印时输入框显示为最终文本态
- [ ] A5横版右侧宣传区打印保留
- [ ] 本页小计每页独立计算，金额总计+大写仅末页显示
- [ ] 打印按钮可选先进入预览态再触发 window.print()

## 移动端适配

- [ ] 纸张按 1:1 固定尺寸渲染，不缩放、不重排、不转卡片
- [ ] 小屏幕通过横向/纵向拖动查看完整纸张
- [ ] 浮层面板 portal 到 app-container，不受纸张边界裁剪
- [ ] 移动端默认单页聚焦模式，可切换连续滚动

## 性能

- [ ] 单页聚焦模式永远只渲染 1 页 DOM
- [ ] 连续预览模式每页骨架 DOM 固定，数据原子更新
- [ ] 浮层面板打开时挂载、关闭时卸载，不常驻
- [ ] 翻页/切模板只更新数据，不重建骨架 DOM

- [ ] 单页聚焦翻页、页码导航正常
- [ ] 任意空白行点击录入、填满自动追加新页
- [ ] 单元格编辑、浮层面板弹出不被裁剪、保存/失败反馈正常
- [ ] 视图切换不丢数据、localStorage 记忆偏好
- [ ] 打印预览纯净显示、打印输出纸张尺寸正确、不含应用UI
- [ ] A5横版宣传区、A5竖版签字栏显示正确
