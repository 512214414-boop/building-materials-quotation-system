# 采购清单真实单据视图（A4/A5 切换）顶层设计方案 v2

## 一、顶层判断

**可行。采购清单默认采用真实单据视图，单据即录入界面，所见即所得。**

采购清单的业务特征决定了它天然适合单据形态：

- 单笔订单行数通常不多，一张 A5 手写单基本能容纳。
- 一线人员（客户、仓管、司机）对手写单据形态极度熟悉，零学习成本。
- 单据是「一叠纸」而不是「一张表格」，用户心理模型是翻本子，不是操作数据网格。
- 所有编辑行为（点击改字、浮层选品、按钮触发辅助功能、右键更多菜单）都可以在单据上完成，不需要切走。

> **核心定位：采购清单默认以真实单据视图呈现，表格视图降级为「高级批量操作视图」保留。两种视图共用 `document_lines` 数据，一键切换。屏幕所见即打印所得。**

## 二、核心设计思想（v2 升级）

### 1. 纸面工作区（Paper Workspace），而非单页容器

- 单据视图不是「一页纸+翻页按钮」，而是一个**纸面工作区**。
- 支持两种浏览模式：
  - **连续预览模式（默认）**：多页纸张垂直排列，可滚动查看所有页，像 Word 打印预览。
  - **单页聚焦模式**：只显示当前页，屏幕居中，适合专注录入。
- 每页是独立纸张 DOM，有真实阴影、页边距、页眉、页脚、页码。
- 翻页时只替换/更新数据，不重建骨架 DOM。

### 2. 全页空白行可填，不限顺序

- 每页末尾补空白行至满页，但空白行不是"追加触发器"。
- **任意空白行**点击即可开始输入，用户可以跳过中间行直接填后面的行。
- 空白行输入有效数据后变为真实数据行；该行下方空白行保持空白。
- 当一页所有行（含原本空白行）都填满有效数据时，自动在后面追加新一页。

### 3. 编辑态与预览态分离

- **编辑模式**：单据周围有工具栏、行内更多菜单按钮、可触发浮层面板，用于日常录入。
- **打印预览模式**：隐藏所有编辑 UI，只留纯净纸张，屏幕效果 = 打印效果。
- 点击「打印」按钮自动进入预览态，然后调用 `window.print()`。
- 用户也可以手动切换到预览态检查效果。

### 4. 浮层面板不被纸张裁剪

- 产品选择、单位价格展开、识别订单结果等浮层面板，通过 `getPopupContainer` 指向 **`.app-container`（应用主容器）**，而非纸张内部。
- 面板以触发单元格为锚点定位，但渲染层级在纸张之上，不受纸张 `overflow:hidden` 裁剪。
- 沿用现有 FloatPanel 组件和 PanelTree 级联关闭机制。

### 5. 两层切换，主次分明

- **主切换（ViewFrame 操作栏）**：只有「单据视图」「表格视图」两个按钮。
- **单据内工具栏**：在单据视图内部提供纸张模板切换（A4 竖版 / A5 横版 / A5 竖版）、浏览模式切换（连续 / 单页）、打印预览、打印按钮。
- 纸张选择不占据主操作栏空间。

## 四、需要纳入顶层考虑的十二个维度

### 4.1 视图定位：谁是默认？表格视图还有什么用？

| 维度 | 单据视图（默认） | 表格视图（高级备用） |
|---|---|---|
| 主要用途 | 日常开单、录入、确认、打印 | 大批量操作（50行+）、批量删除、排序调整、复杂筛选 |
| 信息密度 | 按真实单据（A5约10行） | 极高（一屏几十行） |
| 编辑能力 | 完整（点击编辑、浮层选品、新增/删除） | 完整 |
| 默认状态 | 采购清单/员工端报价默认进入 | 手动切换 |
| 培训成本 | 零（手写单即视感） | 需要理解表格概念 |
| 移动端 | 1:1纸张拖动，符合直觉 | 横向滚动，信息密度高 |

**结论**：采购清单默认单据视图；表格视图保留给高级用户做批量操作，不删除。

### 4.2 分页与浏览模式

- **分页计算**：按模板 `rowsPerPage`（A4约26行、A5横约11行、A5竖约17行）切片。
- **连续预览模式（默认）**：所有页垂直排列，页与页之间留 16px 间距，滚动查看。
- **单页聚焦模式**：当前页居中显示，前后页折叠或隐藏，提供"上一页/下一页"按钮。
- **空白页策略**：至少保证有1页空白行可用；当前页填满自动追加新页；"下一页"按钮永不禁用（可随时跳到空白页）。
- **性能**：连续预览模式下，视口外 2 屏以外的页面用占位符懒渲染，滚动到附近再挂载。
- **页码**：页脚居中显示"第X页/共X页"（这是打印到纸上的真实页码）；工具栏也有页码导航辅助。

### 4.3 编辑交互：全字段可编辑，行为与表格一致

- **行内编辑**：数量、单价、备注、产品信息等单元格点击后进入编辑态。
- **输入框**：使用 DsInput variant="plain"，尺寸与文本态一致，无视觉跳动。
- **快捷键**：Enter/Tab/失焦提交，Escape 回滚，Tab 可在同页单元格间跳转。
- **浮层面板**：产品信息点击弹出 ProductPicker；单位/售价/进价点击弹出 UnitPriceExpandPanel；所有面板复用表格视图的组件，通过 portal 渲染到 `.app-container`。
- **空白行录入**：点击任意空白行任意可编辑单元格即可开始输入，无需先点"新增行"按钮。
- **行删除**：行内"更多"菜单（第一列或最后一列）提供删除选项。
- **失败回滚**：保存失败时显示行内红叹号 + message.error，调用 refresh/loadById 显式刷新，禁止 remount。

### 4.4 字段完整映射

#### 页眉区
- **单据标题**：客户端="采购清单"/"订货单"；员工端="重庆鸿翔建材配送销货单"/"销售单"（可配置）
- **订单编号**：`documents.document_no`
- **购货单位/客户**：`documents.customer.name || documents.customer.company || '—'`
- **客户地址**：`documents.customer.address`（A5竖版显示）
- **客户电话**：`documents.customer.phone`（A5竖版显示）
- **日期**：`documents.created_at` 格式化
- **备注**：`documents.remark`（头部整体备注）
- **录单日期/单据编号前缀**：如 "XS-2025-11-05-06371"（A5竖版风格）

#### 表体区（列顺序固定）
- **序号**：全局连续序号（(pageIndex * rowsPerPage) + rowIndex + 1）
- **产品信息**：`document_lines` 的产品快照（品牌+名称+规格），非标数据显示待确认标记
- **数量**：`document_lines.qty`
- **单位**：`document_lines.unit`
- **单价**：`document_lines.unitPrice`
- **金额**：`document_lines.amount`（= qty * unitPrice）
- **备注**：`document_lines.remark`

#### 页脚区
- **金额总计**：`documents.total_amount`（仅最后一页显示）
- **大写金额**：总计金额的中文大写（仅最后一页显示）
- **本页小计**：当前页所有行金额累加（每页显示）
- **温馨提示**：固定文案（"本销货单（合同）签字盖章，具有法律效益..."）
- **地址**：公司地址（固定文案）
- **电话**：公司电话（支持多个号码）
- **制单人**：`documents.creator.name` 或 "——"
- **收货单位及经手人签字栏**：A5竖版/特定模板显示下划线签字区
- **页码**："第X页/共X页"，居中

#### A5横版专属区
- **右侧固定宣传区**：经营范围竖排文字（"管材管件、电线电缆、开关插座、油漆涂料、五金工具、水暖卫浴..."），打印时显示。

### 4.5 视图切换与数据同步

- 切换单据/表格视图时不重新请求后端。
- 切换纸张模板时即时重排（重新分页），不请求后端。
- 任何视图保存成功后，通过 refresh/loadById 同步数据到另一视图。
- 当前视图状态（单据/表格）和纸张模板记忆到 localStorage。
- 首次进入默认：单据视图 + A5竖版。

### 4.6 打印输出

- 浏览器打印 + `@media print` CSS，不引入服务端PDF生成。
- 打印样式：
  - 隐藏 AppShell 导航、操作栏、单据内工具栏、所有编辑UI（更多菜单按钮、输入框焦点样式）。
  - `@page size` 跟随当前模板（A4 / A5 landscape / A5 portrait）。
  - 多页时每页 `page-break-after: always`，页眉页脚每页重复。
  - 输入框/选择框打印时显示为最终文本。
  - A5横版右侧宣传区打印保留。
- 打印预览模式：屏幕上一键切换，效果与打印完全一致，方便用户检查。
- 打印按钮：在单据内工具栏，点击后先进入预览态（可选），再触发 `window.print()`。

### 4.7 移动端适配

- 沿用固定画布原则：纸张按1:1尺寸渲染，不缩放、不重排、不转卡片。
- 小屏幕通过横向/纵向拖动查看完整纸张。
- 浮层面板在单据上正常弹出，portal 到 app-container，定位不受纸张边界限制。
- 连续预览模式在移动端默认只显示当前页（避免纵向过长），可切换连续滚动。

### 4.8 权限控制

- 所有字段、按钮、菜单对所有账号可见。
- 无权限时字段为只读（不可点击进入编辑态），按钮点击提示"无权限"。
- 不隐藏任何元素。

### 4.9 客户端与员工端差异

| 项 | 客户端（PurchaseList） | 员工端（PurchaseQuote） |
|---|---|---|
| 单据抬头 | 采购清单/订货单 | 销货单/配送单 |
| 默认状态 | demand_pending，可编辑数量、选品 | 根据状态决定可编辑字段 |
| 主要操作 | 加产品、填数量、提交确认 | 报价、配货、收款、对账 |
| 打印用途 | 客户自己留档、下单凭证 | 配送签收、财务记账 |
| 共用 | 同一套模板组件，通过 props 传入抬头、字段配置、可编辑性 |

### 4.10 模板配置策略

**第一阶段（快速验证）**：
- 公司抬头、地址、电话、温馨提示、经营范围等固定文案，硬编码在模板常量中。
- 数字大写转换工具函数内置。

**第二阶段（配置化）**：
- 新增系统配置项，后台可修改公司打印信息。
- 模板组件从配置读取抬头等信息。

### 4.11 与现有表格交互规范的兼容

- 单元格编辑复用表格 CellEditor 逻辑，不另造一套。
- 分页器沿用"下一页永不禁用"原则。
- 浮层面板复用 FloatPanel + PanelTree 级联关闭机制。
- 非标产品数据显示 InfoCircleOutlined 待确认标记，与表格一致。
- 保存成功/失败反馈复用行内绿勾/红叹号 + message 机制。
- 骨架常驻 + 原子更新，禁止 version state 强制 remount。

### 4.12 性能策略

- **单页聚焦模式**：永远只渲染1页DOM，性能最优。
- **连续预览模式**：
  - 每页骨架DOM（表头+表体框架+页脚）固定。
  - 数据行通过数据驱动渲染。
  - 视口外2屏以外页面用高度占位符，滚动到附近再挂载真实DOM。
  - 20页以内的订单（绝大多数场景）直接全量渲染，无需懒加载。
- **浮层面板**：打开时挂载，关闭时卸载，不常驻DOM。

## 六、关键交互流程

### 6.1 进入采购清单
1. 读取 localStorage 中保存的视图偏好（默认单据视图+A5竖版）。
2. 加载 documents + document_lines 数据。
3. 单据视图按模板分好页，默认显示第1页（连续预览模式则从第1页开始滚动）。

### 6.2 在空白行录入新产品
1. 用户点击任意空白行的"产品信息"单元格。
2. 弹出 ProductPicker 浮层面板（portal到app-container）。
3. 用户搜索/选择/新建产品后，面板关闭，该行填充产品信息。
4. 焦点自动跳到数量单元格，用户继续输入。
5. Enter/失焦后提交该行到后端。
6. 如果当前页所有行都填满，自动追加新页。

### 6.3 修改已有行
1. 用户点击数量/单价/备注单元格。
2. 进入行内编辑态，直接修改。
3. Enter/Tab/失焦提交到后端。
4. 成功：行内绿勾一闪 + message.success。
5. 失败：行内红叹号 + message.error + 显式刷新。

### 6.4 切换纸张模板
1. 用户在单据内工具栏点击 A4/A5横/A5竖 按钮。
2. 同一批数据按新模板 rowsPerPage 重新分页。
3. 如果当前页超出新总页数，自动跳到最后一页。
4. 记忆模板选择到 localStorage。

### 6.5 切换浏览模式
1. 用户点击"连续预览"/"单页聚焦"切换按钮。
2. 连续→单页：当前滚动位置最近的页面作为当前页，只渲染该页。
3. 单页→连续：渲染所有页，滚动到之前的当前页位置。

### 6.6 打印预览与打印
1. 用户点击"打印预览"按钮。
2. 进入预览模式：隐藏工具栏、更多菜单按钮、输入框边框，纸张纯净显示。
3. 用户确认无误后点击"打印"按钮。
4. 触发 `window.print()`，`@media print` 样式生效。
5. 打印对话框纸张尺寸跟随模板。

### 6.7 删除行
1. 用户点击行内"更多"菜单按钮。
2. 选择"删除"，确认对话框弹出。
3. 确认后删除该行。
4. 如果删除后当前页变空且不是最后一页，自动回到上一页或调整页码。

### 6.8 切换到表格视图
1. 用户点击主切换栏"表格视图"按钮。
2. 切到 UnifiedTable，保留当前数据状态和页码位置。
3. 用户可进行批量操作。
4. 切回单据视图时数据已同步。

## 七、待决策事项

1. **默认模板与浏览模式**
   - 推荐：A5竖版 + 连续预览模式。
   - 理由：最接近手写单习惯，连续预览符合电脑屏幕滚动习惯。

2. **表格视图保留程度**
   - 推荐：完整保留，不做删减。
   - 理由：高级用户批量操作需要，开发成本几乎为零（已有）。

3. **A5横版右侧宣传区内容**
   - 推荐：第一阶段按用户提供的样图文字硬编码（经营范围列表）。
   - 后续可配置化。

4. **签字栏是否所有模板都显示**
   - 推荐：A5竖版显示签字栏，A4/A5横版不显示（或可选）。
   - 理由：A5竖版最接近纸质签收单场景。

5. **保存为图片功能**
   - 推荐：第一阶段不做。浏览器打印/导出PDF已满足需求。
   - 后续可基于 html2canvas 实现。

## 八、可行性结论

| 方面 | 评估 |
|---|---|
| 技术可行性 | 高。固定尺寸CSS + 浏览器打印 + React组件，无新技术难点 |
| 数据可行性 | 高。完全复用现有 documents/document_lines，无需改表 |
| 交互可行性 | 高。CellEditor/FloatPanel/ProductPicker 全部可复用 |
| 性能影响 | 低。每页DOM固定，连续预览懒加载，单页模式永远只渲染1页 |
| 移动端可行性 | 高。固定画布拖动，浮层portal，符合现有模式 |
| 培训成本降低 | 极高。所见即真实单据，用户不需要理解"表格"概念 |

**总体结论：建议实施。采购清单默认单据视图（A5竖版+连续预览），表格视图保留为高级备用；三种纸张模板一键切换；编辑预览分离；浮层不被裁剪；打印即所见。**

## 九、与现有规范的衔接

- 与 `table-interaction-v2` 完全兼容：CellEditor、FloatPanel、PanelTree、非标标记、保存反馈全部复用。
- 与 `purchase-list-excel-super-grid` 兼容：分页器"下一页永不禁用"原则在单据视图以"空白页+追加页"形式体现。
- 与 AppShell 规范兼容：单据视图在 ViewFrame children 区域渲染，不破坏全局骨架。
- 与固定画布模式兼容：纸张1:1渲染，移动端拖动查看，不缩放不重排。
- 与权限规范兼容：所有元素可见，无权限只读。
- 与"骨架常驻+原子更新"性能规范兼容：翻页/切模板只更新数据，不重建DOM。
