# 采购清单点击编辑表格 验收清单

## 功能验收

- [ ] 空订单打开采购报价视图，显示 13 个空行，点击任意单元格可录入
- [ ] 有数据时，数据行 + 空行补满本页（如 5 行数据 + 8 个空行）
- [ ] 点击文本态单元格，无视觉跳动地切换到编辑态（input）
- [ ] 编辑态失焦后，无视觉跳动地切换回文本态（div）
- [ ] 翻页功能正常，第 2 页显示空行可录入
- [ ] 调整每页行数（10/20/50）后，重新分页正常
- [ ] Enter 键：提交当前值，焦点移至下一行同列
- [ ] Tab/Shift+Tab：提交当前值，焦点移至同行下一列/上一列
- [ ] Escape：恢复原始值，退出编辑态
- [ ] ArrowDown/ArrowUp：提交当前值，焦点移至下一行/上一行

## 性能验收

- [ ] 50 行数据：滚动流畅，点击编辑无延迟
- [ ] 100 行数据：滚动流畅，点击编辑无延迟
- [ ] 200 行数据：滚动流畅，点击编辑无延迟
- [ ] 500 行数据：滚动流畅，点击编辑无延迟
- [ ] 虚拟滚动启用：仅渲染可视区域内的行（DOM 节点数 < 50）

## 视觉验收

- [ ] 文本态与编辑态切换无视觉跳动（无位移、无闪烁）
- [ ] 焦点视觉反馈：底部 brand 色细线（box-shadow）
- [ ] 列宽稳定：不因焦点切换而变化
- [ ] 文本溢出显示省略号（text-overflow: ellipsis）
